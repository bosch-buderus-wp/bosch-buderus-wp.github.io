| Term                      | Meaning                                                                                                                                                       |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AT                        | Outdoor temperature                                                                                                                                             |
| AW                        | Air Water: air-to-water                                                                                                                                         |
| A7 W35                    | Outdoor temperature of 7 °C and flow temperature of 35 °C                                                                                                     |
| CAN-Bus                   | The outdoor unit and indoor unit are connected to each other via a communication cable, the CAN-BUS [24 V DC, Class III, safety extra-low voltage (SELV)]. |
| COP                       | Coefficient of Performance: performance factor determined under laboratory conditions for various outdoor/flow temperature combinations, e.g. A7 W35          |
| DHW                       | Domestic Hot Water: domestic hot water/service water                                                                                                           |
| Drucksollwert             | Differential pressure at which the heating circuit pump PC1 is controlled                                                                                       |
| EMS-Bus                   | Accessories are connected to the indoor unit via an EMS-BUS [15 V DC, Class III, safety extra-low voltage (SELV)]                                            |
| EVU-Sperrsignal           | Blocking signal from the energy supply company (EVU) - no longer relevant                                                                                      |
| FBH                       | Underfloor heating                                                                                                                                              |
| Endpunkt                  | The end point is the flow temperature reached at the design outdoor temperature (NAT).                                                                         |
| Fußpunkt                  | The base point is the flow temperature reached at an outdoor air temperature of 20 °C.                                                                         |
| Gedämpfte Außentemperatur | Delayed and attenuated outdoor temperature depending on the building type setting (light, medium, heavy). This slows down the control of the flow temperature. |
| Heizkreis                 | Water circuit between the indoor unit and radiators/underfloor heating                                                                                          |
| HK 1                      | Heating circuit 1                                                                                                                                               |
| IDU                       | Indoor Unit = indoor unit                                                                                                                                       |
| JAZ                       | Seasonal performance factor: efficiency of the complete system at the installation site over an entire year                                                   |
| Komfortpunkt              | The comfort point enables the flow temperature to be increased during the transitional period in spring/autumn.                                               |
| K30 RF                    | Bosch WLAN gateway for connecting the heat pump to the app and wireless remote control and for remote maintenance                                               |
| K40 RF                    | Bosch WLAN gateway for connecting the heat pump to the app and wireless remote control, for remote maintenance and energy management (§14a EnWG)             |
| MAZ                       | Monthly performance factor: efficiency of the complete system at the installation site over an entire month                                                     |
| ODU                       | Outdoor Unit = outdoor unit                                                                                                                                     |
| PC0                       | Circulation pump for the primary circuit between the outdoor and indoor units                                                                                   |
| PC1                       | Circulation pump for the heating circuit                                                                                                                        |
| Primärkreis               | Water circuit between the outdoor and indoor units                                                                                                              |
| SG Ready                  | Control via Smart Grid to boost or block the heat pump                                                                                                          |
| TAZ                       | Daily performance factor: efficiency of the complete system at the installation site over an entire day                                                        |
| TC0                       | Temperature sensor for the primary circuit water at the indoor unit outlet (return)                                                                            |
| TC3                       | Temperature sensor for the primary circuit water at the outdoor unit outlet (flow)                                                                             |
| TL2                       | Temperature sensor for the outdoor air inlet at the evaporator                                                                                                  |
| TR5                       | Temperature sensor for the suction gas at the compressor inlet                                                                                                  |
| T1                        | Outdoor temperature sensor for controlling the flow temperature with outdoor temperature-controlled regulation                                                |
| UI 800                    | Bosch control panel on the indoor unit                                                                                                                          |
| WW                        | Domestic hot water/service water                                                                                                                                 |
| Zuheizer                  | Electric backup heater that supports heat pump operation when the bivalent temperature is undershot and during emergency operation.                           |
