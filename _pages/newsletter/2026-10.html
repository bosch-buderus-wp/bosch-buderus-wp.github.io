Die Heizsaison ist angekommen: Fast alle Anlagen mit gemeldeten Tageswerten haben im Oktober mindestens einmal Heizenergie erfasst. Wie effizient und wie viel Strom eine Anlage benötigt, hängt unter anderem von Gebäude, Wetter und Warmwasserbedarf ab.

METRIKEN · NEU

Wie viel Heizleistung braucht dein Haus?

Die neue Heizlastschätzung stellt die mittlere Heizleistung einer Anlage der Außentemperatur gegenüber. Sind genügend geeignete Heiztage vorhanden, zeigt eine Trendlinie, wie sich der Leistungsbedarf entwickelt. Mit hinterlegter Normaußentemperatur ist auch eine Hochrechnung möglich.

GRAFANA · LOKALE API

Deine Wärmepumpe im Dashboard

Das neue Grafana-Dashboard liest Live-Werte und die verfügbare Historie direkt über die lokale API von K 40 RF oder MX400. EMS-ESP und eine zusätzliche Datenbank brauchst du dafür nicht. Voraussetzung sind Grafana, die Infinity-Datenquelle und ein Gateway mit Firmware 15.00.01 oder neuer.

Die Animation zeigt verschiedene Bereiche des Dashboards. Die gespeicherte Gateway-Historie ist zeitlich begrenzt.

Dashboard entdecken →

SMART HOME

Home Assistant trifft lokale API

Für Home Assistant gibt es inzwischen mehrere Community-Integrationen, die das K 40 RF oder MX400 im Heimnetz auslesen. Sie werden als benutzerdefinierte Repositories installiert. Die lokale API bietet Lesezugriff; zum Ändern von Einstellungen und für zusätzliche Entitäten bleibt EMS-ESP eine Alternative.
